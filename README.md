# E-commerce Recommendation System

## Project Overview
This project is an **E-commerce Recommendation System** built using Python. It recommends products to users based on multiple approaches, including **collaborative filtering, rating-based recommendations, content-based recommendations, and hybrid methods**. A **Flask web app** allows users to search for products and get personalized recommendations in real-time.

## Features
- Collaborative Filtering: Suggests products based on user behavior similarities.
- Rating-Based Recommendation: Uses product ratings to suggest popular or highly-rated items.
- Content-Based Recommendation: Suggests products similar to the user’s past preferences.
- Hybrid Recommendation: Combines collaborative and content-based methods for better accuracy.
- Flask Web App: Interactive interface for searching products and displaying recommendations.

## Dataset
- **Source:** Welmart e-commerce dataset
- **Format:** TSV format 
- Includes product IDs, user ratings, and product descriptions.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- HTML/CSS/Bootstrap (for front-end)
